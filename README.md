## ✨ 功能特性

### 📚 Tab 1: 时间戳互转 (Timestamp Converter)
* **实时 UNIX 计时器**：高精度的当前 Unix 时间戳每秒自动刷新显示，支持一键快捷复制或一键填入下方转换框。
* **双向智能解析与清洗**：
  * **时间戳 → 日期**：输入框内置强数字过滤防御，自动实时剔除空格、逗号、引号等日志常见非数字杂质。智能识别 **10 位（秒）**与 **13 位（毫秒）**时间戳，并支持手动切换。
  * **日期 → 时间戳**：通过浏览器原生的 `datetime-local` 选择本地时间，秒级（10位）、毫秒级（13位）时间戳同步输出，并支持分态独立复制。
* **多时区墙上时刻对照**：基于浏览器原生 `Intl` 高级 API，实时联动计算并按顺序一致地展示 UTC、北京/上海、东京、洛杉矶（美西）、纽约（美东）、伦敦的当前或指定时刻。
* **多语言代码片段联动**：动态提取当前选择的时间戳，实时生成包括 **JavaScript**、**Python**、**Java**、**Go** 在内的四种主流语言的获取与转换脚手架样式代码，点击即可复制。

### 🤖 Tab 2: Cron 工作台 (Cron Workspace)
* **标准 Linux 规范解析**：完美对齐标准 5 位（分 时 日 月 周）Linux crontab 规范。支持通配符（`*`）、范围限制（`1-5`）、步长步进（`*/15`、`1-30/10`）以及逗号离散枚举（`1,3,5`）的高级组合可视化拆解。
* **可视化字段拆解**：针对输入的表达式进行细粒度拆包，将分、时、日、月、周独立渲染到对应看板，语法对错一目了然。
* **纯表单引导式生成**：不依赖 AI，基于纯前端互斥置灰逻辑。选择每天、每周（可多选星期）、每月（可选择具体几日）后，系统**自动互斥锁定冲突字段**（例如选择每周时自动将“日”锁定为 `*`），从源头上断绝拼出逻辑歧义表达式的可能。
* **未来执行预测与联动跳转**：支持未来 **5次、10次、20次** 执行时间的精准时区预测。列表中生成的未来时刻**支持点击联动跳转回 Tab 1**，直接填入该时间戳进行二次转化或生成对应的代码片段。

## 🛠️ 核心硬核技术要点 (Under the Hood)

为了确保工具在生产环境中达到工业级的健壮性，底层代码实现了以下三个关键算法与防御机制：

* **DOM/DOW 的 OR 逻辑硬核修正**：根据 Linux crontab 标准行为，当“日(DOM)”与“周(DOW)”字段同时显式指定（即两者均非 `*`）时，它们之间是 **“或（OR）”** 关系而不是“与”关系。本工具完美还原了这一反直觉的底层行为，并在语义描述区域常驻**黄色高亮警示**，防止开发或运维人员产生生产环境误判。
* **Intl 引擎午夜 24 点回归漏洞修复**：部分现代浏览器在执行 `Intl.DateTimeFormat` 翻译特定时区午夜时刻时，可能会异常返回 `24:00` 从而引发日期级倒退隐患。本工具在底层引入了名义分钟归一化重置算法，确保跨时区转换的绝对精确。
* **夏令时 Spring Forward 跳变与任务漏判补偿**：在进行未来执行预测时，不依赖脆弱的本地时区增量，而是采用纯粹的 UTC 毫秒数按 60 秒步长层层推进。当游标检测到夏令时前调产生物理空档时，将自动启用名义墙上时间差补偿算法，确保被跳过的定时任务在当前局边界合并正确触发，避免漏判。
* **同步计算性能与防卡死保护**：为了防止用户输入如“2月31日”等永不存在的极端极端日期组合导致主线程死循环死锁，工具将前向遍历上限硬锁在 **2 年（约 105 万次循环）**。计算在数十毫秒内即可安全熔断并抛出友好提示，绝不阻塞主线程。
* **等宽数字排版设计**：针对高频刷新的当前计时器、密集排列的多时区对照表和未来执行预测列表，全局统一使用 `font-variant-numeric: tabular-nums;` 样式，彻底消除由于数字字符宽度不一引发的视觉抖动。

## ❌ 不做的功能 (v1 明确排除范围)

为保持工具的纯粹性、轻量化与高可用性，以下功能被明确排除：
* **不支持** 6 位 Quartz 规范（秒级 Cron）表达式，坚持标准 5 位 crontab 规范。
* **不提供** 任何 AI 自然语言对话输入转换 Cron（改由更高效、确定性更高的互斥引导式表单代替）。
* **不支持** 自定义时区数据库文件的上传（仅使用浏览器原生的 IANA 时区列表）。
